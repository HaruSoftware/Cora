# 📌 Projeto Acadêmico - FATEC Franca (Dr. Thomaz Novelino)

**Curso:** Análise e Desenvolvimento de Sistemas (ADS)  
**Projeto:** **Cora**  

Cora é um aplicativo voltado para **comércios em geral**, com foco em **facilitar a gestão** e **melhorar a experiência dos clientes**.

---

## 🎯 Objetivo
- Auxiliar comerciantes na organização de seus negócios  
- Oferecer ferramentas práticas de gestão  
- Proporcionar uma experiência mais eficiente e agradável para os clientes
